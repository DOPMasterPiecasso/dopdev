# DOP — Pricing & Copywriting Strategy

Dokumen brainstorm: positioning, harga saat ini (diskon 25% dari harga saran awal), dan copywriting siap tempel untuk semua halaman dopdev.com.

**Target market:** Service businesses (barbershop, klinik, salon, fitness) di Singapore & Australia.
**Mata uang:** SGD.

---

## 1. Pricing Table (Harga Saat Ini — −25%)

| Service | Harga Awal (sarankan) | **Harga Sekarang (−25%)** |
|---|---:|---:|
| Landing Page (promo) | S$1,200 | **S$900** |
| Company Profile Website | S$2,500 | **S$1,875** |
| Web Booking System | S$4,500 | **S$3,375** |
| Custom Web System | S$7,500 | **S$5,625** |
| **Website Revamp (Tier 1)** | S$1,800 | **S$1,350** |
| **Website Revamp + Fitur (Tier 2)** | S$3,900 | **S$2,925** |
| Hosting & support (opsional) | S$90/mo | **S$68/mo** |

### Catatan strategi harga

- **Anchor:** semua harga tampil sebagai harga normal. Kalau mau tampilin diskon, jangan coret-strike fiktif — pakai framing *"Intro Offer: first 5 clients this month"* di LP promo saja.
- **LP S$900 = alur masuk (top of funnel).** Jangan taruh berdampingan dengan Revamp di halaman yang sama supaya tier revamp tidak terasa mahal.
- **Revamp S$1.350 < Company Profile S$1.875** → keputusan mudah: website sudah ada = revamp, jangan rebuild.
- **Revamp + Fitur S$2.925 < Booking System S$3.375** → entry point: klien yang belum siap bayar booking system masuk lewat sini, lalu upsell modul berikutnya (+S$900–1.100 per modul).
- **Add-on fitur terpisah:** +S$900–1.100 per modul (booking, payment deposit, member portal, CRM).

### Scope guardrail

| | Tier 1: Revamp Only | Tier 2: Revamp + Fitur |
|---|---|---|
| Termasuk | Desain baru, mobile-first, speed, copy polish, SEO basics, CTAs — konten & domain lama dipakai ulang | Semua Tier 1 + 1–2 modul pilihan |
| Batas | Maks 5 halaman, tanpa integrasi baru | +1 modul per S$900–1.100 |
| Bukan termasuk | Ganti semua konten → masuk harga Company Profile baru | Scope custom → quote terpisah |
