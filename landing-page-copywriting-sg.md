# Copywriting Landing Page Promo Dopdev (Singapura)

Copy halaman dalam bahasa Inggris (bahasa pembeli), catatan dalam bahasa Indonesia. Teks dalam kurung siku adalah catatan untuk tim, bukan untuk ditampilkan.

**Tujuan:** satu aksi, yaitu calon klien menekan tombol WhatsApp untuk meminta mockup gratis.
**Target:** bisnis home service di Singapura (aircon, cleaning, electrician, plumber, renovation).
**Urutan section:** Navbar → Hero → Problem → Offer → Revamp & Care → Value → Portfolio → How it works → Promise → FAQ → Final CTA → Footer.

## Aturan copy

- Jangan menambahkan testimoni, angka hasil, atau logo klien sebelum benar-benar ada.
- Kuota "5 spots" dan harga promo harus ditepati. Kalau slot habis, ubah copy-nya.
- Penawaran utama tetap landing page S$690. Revamp dan Care hanya pelengkap, jangan dijadikan CTA utama.
- Jangan menjanjikan peringkat Google.
